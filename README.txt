CPS by Rafu - Modern CPS Control Panel
Developed by Rafu

Choose 1-60 CPS with the slider or use a quick preset. Press Start/F6 to arm
the clicker, then hold the left mouse button in the target app. Release the
button or press Stop/F7 to pause. F8 is the emergency stop. Hotkeys can be
changed in the Shortcuts panel.

The clicker pauses while the cursor is over its own window. The app uses the
Windows SendInput API and a low-level mouse hook to detect the physical hold.

Build with MinGW-w64 by running build.bat from this folder.
